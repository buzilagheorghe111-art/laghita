# Site oficial – Service Auto „La Ghiță“

Site static HTML/CSS/JavaScript, pregătit pentru GitHub Pages.

## Publicare prin GitHub Pages
1. Deschide depozitul `service-auto-la-ghita-site`.
2. Încarcă fișierele `index.html`, `style.css` și `script.js` în rădăcina depozitului.
3. Deschide **Setări** → **Pagini**.
4. La **Construire și implementare**, selectează **Implementare dintr-o ramură**.
5. Alege ramura `principală` și folderul `/ (root)`, apoi apasă **Salvare**.
6. Așteaptă publicarea. Adresa va fi `https://buzilagheorghe111-art.github.io/service-auto-la-ghita-site/`.

Linkurile de descărcare trimit către depozitul GitHub Releases existent pentru instalatoare.
